Emulador CHIP-8

Uma CPU dos anos 70 emulada do zero em C++: memória, registradores, pilha, timers e os 35 opcodes. O mesmo núcleo que roda na versão Win32 foi compilado para WebAssembly, então dá para jogar aqui mesmo.

Use o teclado do computador (as letras no canto de cada tecla) ou toque nas teclas. Arquivos que você abrir ficam só no seu navegador.

Como funciona

Núcleo em C++

A classe Chip8 faz o ciclo de busca, decodificação e execução sem saber nada de janela ou teclado. É a mesma usada no executável para Windows.

WebAssembly

Uma ponte pequena (web/chip8_web.cpp) expõe cinco funções. O Emscripten compila tudo para .wasm no GitHub Actions a cada push.

60 quadros por segundo

O JavaScript chama um quadro por requestAnimationFrame: roda N instruções, atualiza os timers a 60 Hz e desenha a tela 64×32 no canvas.

Testado

Os opcodes têm testes automatizados que rodam no Linux com AddressSanitizer e UBSan, e no Windows com MinGW.
